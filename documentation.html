Introduction

FocusTube is an intentional, open-source streaming alternative engineered specifically to pull educational video content out of algorithmic distraction loops and reframe lectures into ultra-clean workspace templates.

Modern video platforms are designed for maximum retention through distraction. Recommended videos, comment sections, and autoplay features actively work against deep cognitive focus. FocusTube strips all of this away, providing a Neo-Brutalist interface dedicated solely to the content you actively search for.

Philosophy: The tool does not prescribe what you learn; it only enforces the environment in which you learn it.

Local Installation

FocusTube runs on a lightweight Node.js backend using Express to route API requests securely. To get the platform running on your local machine, follow these steps.

Prerequisites

  • Node.js (v18.0 or higher recommended)
  • NPM (Node Package Manager)
  • A valid YouTube Data API v3 Key

Step-by-step Setup

Terminal 
# Clone the repository
git clone https://github.com/yourusername/focustube.git

# Navigate into the directory
cd focustube

# Install backend dependencies
npm install

# Start the development server using Nodemon
npm run dev
Note: If you encounter an ERR_MODULE_NOT_FOUND error, ensure your package.json includes "type": "module" and that all local imports end with the .js extension.

Environment Variables

FocusTube requires environment variables to securely communicate with external APIs without exposing your keys to the frontend client.

Create a .env file in the root of your server/ directory and populate it with the following:

.env 
PORT=3000
YOUTUBE_API_KEY=your_google_cloud_api_key_here

The Search Engine

The Search Engine is the gateway to FocusTube. It acts as an algorithmic firewall, preventing endless scrolling by forcing you to input explicit intent before any content is rendered.

Features

  • Smart Link Detection: Paste a direct YouTube URL (e.g., https://youtube.com/watch?v=...) into the search bar to instantly bypass the search results and jump directly into the Theater Player.
  • Skeleton Loading: Advanced CSS shimmer animations maintain layout stability while the server fetches data.
  • Neo-Brutalist Cards: Results are rendered as responsive, glassmorphism cards that highlight the duration, title, and channel, while suppressing clickbait thumbnails via CSS overlays.

Theater Player

The core of the FocusTube experience. The player forces a massive 16:9 cinematic wrapper around the video iframe, locking out all native YouTube recommendations.

Lights Out Mode

By clicking the Lights Out button in the metadata panel, the UI triggers a cinematic focus state. The background transitions to pure black, and all peripheral tools (metadata, sidebars, navigation) are aggressively blurred and dimmed to 5% opacity, eliminating all visual noise outside the video frame.

Focus Hub Tools

Located on the right side of the Theater Player, the Focus Hub provides native productivity utilities to prevent you from opening new browser tabs.

Session Tracker (Pomodoro)

A fully integrated JavaScript timer engine. Click the settings gear to configure your session times. The state is saved locally to your browser via localStorage.

Native Calculator

A brutally styled, tactile calculator overlay. It intercepts keyboard input and button clicks, securely evaluating math expressions using a sandboxed JavaScript engine to handle precision floating-point arithmetic.

Quick Notes System

An auto-saving scratchpad. As you type, the content is continuously written to browser storage. Click the download icon in the header to instantly compile your notes into a .txt file and save it to your local machine.
